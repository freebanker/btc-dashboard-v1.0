# BTC Dashboard V1.0

Professional Bitcoin market-intelligence dashboard foundation.

## Stack
Next.js + React + TypeScript + lucide-react

## V1.0
- BTC price overview and trend chart
- ETF / institutional signal cards
- Position cost basis at $85,730
- $5,000 add-on planner
- Support / resistance and risk panel
- Macro, news and weekly catalyst placeholders

## Run
npm install && npm run dev

> Market figures in this first UI build are placeholders until live data connectors are configured.


## V2 development
On-chain liquidity and ETF flow modules are being integrated incrementally.
